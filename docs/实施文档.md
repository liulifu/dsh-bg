# dsh-bg 实施文档

> 插件：DSH web 页面背景切换器
> 版本：0.1.0 · 语言：JavaScript（browser bundle + host 占位）
> 适用范围：DSH Web GUI（`dsh web` / `--profile web`）

---

## 1. 需求背景

用户希望在 DSH Web 界面自由更换背景。可更换范围为 **左侧固定面板**（会话列表
sidebar）与 **右侧抽拉面板**（工具检查 details 栏）。更换逻辑分为三种模式：

1. **左面板**：只给左侧固定面板换背景
2. **右面板**：只给右侧抽拉面板换背景
3. **左右无缝**：左右面板显示同一张图，视觉上无缝衔接为一张图
   （左右是同一张图片的左右切片，对话栏显示图片中间部分）

需求演进（会话 94c27f94 多轮迭代）：

- 基础背景图片更换 + 设置入口（通用设置 → 外观 → 背景行）
- 当前背景**预览**（迷你三栏布局示意图）
- 图片库：上传 / 粘贴 / 缩略图选择 / 删除
- **文字颜色手动调整**（灰度滑杆 + 可选 RGB 模式），配合背景保证可读性
- 背景**压暗遮罩**、**图片不透明度**、**模糊度**三个滑杆
- **动态壁纸**：支持 MP4 循环播放（静音、铺满、可模糊/调透明度）

## 2. 架构设计

### 2.1 插件形态

dsh-bg 是**纯浏览器端（client）插件**：宿主侧（`lib/index.js`）是无行为占位，
所有逻辑在 `lib/client.js`（browser bundle）中。通过 `package.json` 的
`dsh.client` 声明注入 `slots` 服务，`dsh.bundle.patch` 声明组合补丁：

```json
"dsh": {
  "client": { "platform": "web", "inject": ["slots"] },
  "bundle": { "patch": "./cordis.patch.yml" }
}
```

`cordis.patch.yml` 插入插件行，client 半被 client-modules 扫描进浏览器启动图：

```yaml
- insert:
    - id: dsh-bg
      name: dsh-bg
```

### 2.2 数据流

```
localStorage (dsh-bg:config)  ⇄  React 状态 (BackgroundRow)
                                       │
                                       ├─ cssFor(config, isVideo) → <style> 注入
                                       ├─ applyVideo(config)      → <video> 元素管理
                                       └─ applyConfig(config)     → 两者统调
```

- 配置持久化：`localStorage["dsh-bg:config"]`（JSON，含图片库）
- 视频媒体：**IndexedDB**（`dsh-bg` 库 / `media` 存储，Blob 按 id 存），
  对象 URL 缓存于内存 Map，避免 localStorage 配额压力

### 2.3 状态结构（defaultConfig）

```js
{
  enabled: false,        // 背景总开关
  mode: "both",          // left | right | both（左右无缝）
  imageId: "sample-aurora",
  overlay: 0.25,         // 压暗遮罩不透明度 [0, 0.8]
  blur: 0,               // 高斯模糊 [0, 40px]（UI 上限 24）
  imageOpacity: 1,       // 图片/视频自身不透明度 [0, 1]
  images: [{ id, name, dataUrl|kind:"video", addedAt }],  // 图片库，最多 8 项
  text: { enabled, rgbMode, gray, r, g, b } // 文字颜色调整
}
```

内置一张可删除的示例背景（内联 SVG 极光渐变 data URL），开箱即可试用三种模式。

## 3. 核心实现

### 3.1 CSS 引擎（cssFor）

关键难点：DSH 布局类名是 **CSS Modules 哈希**（如 `pI_x6G_sidebarCol`），
哈希前缀跨版本会变。解法：用**稳定的语义后缀**匹配：

```js
const SEL = {
  frame:     '[class$="_frame"]:has(> [class$="_sidebarCol"])',
  leftCol:   '[class$="_sidebarCol"]',
  leftInner: '[class$="_sidebarCol"] > div',
  centerCol: '[class$="_centerCol"]',
  rightCol:  '[class$="_detailsCol"]',
  rightInner:'[class$="_detailsCol"] > div'
};
```

- 左栏 / 右栏用 `[class$="_sidebarCol"]` / `[class$="_detailsCol"]` 匹配
- 整屏模式（both）把图片铺在 AppFrame 根（`[class$="_frame"]:has(> [class$="_sidebarCol"])`），
  `:has()` 用于与其它插件（subagent、user-questions）发出的同名 `*_frame` 对话框区分
- 面板内部不透明根节点（SidebarRoot / ConversationRoot / DetailsPanel）必须置为
  `transparent`，否则会盖住列背景：
  `[class$="_sidebarCol"] > div { background: transparent !important }`
- **设置面板排除**：设置菜单渲染在 sidebar 列内（唯一的 `*_panel` 元素），
  用 `:not([class$="_panel"]):not([class$="_panel"] *)` 保持其不透明

生成规则分四段：

1. **surface**：`position:relative; z-index:0; background:transparent !important`
   （建立独立层叠上下文）
2. **图片层（::before）**：`z-index:-1; background:url(dataUrl) center/cover;
   filter:blur(); opacity:` — 模糊与透明度只作用于图片，绝不影响其上文字
3. **压暗遮罩（::after）**：`z-index:-1; background:linear-gradient(rgba(14,16,20,o))`
4. **透明化规则**：按模式把对应列内所有非设置面板元素置透明

### 3.2 文字颜色调整（textColorRule）

覆盖主题文字令牌（在作用域上重声明 CSS 变量），作用于有背景的面板范围：

```css
{scope} {
  --dsw-alias-label-primary:   rgba(c, 1);
  --dsw-alias-label-secondary: rgba(c, .75);
  --dsw-alias-label-tertiary:  rgba(c, .55);
  --dsw-alias-label-caption:   rgba(c, .45);
}
```

- 灰度模式（默认）：单滑杆 0-255，整体调文字明度
- RGB 模式（开关，默认关）：R/G/B 三滑杆精确调色
- 次级文字自动带透明度保持层次
- 设置菜单自身文字恢复主题色（从 `document.body` computed style 读取原令牌，
  `:is(scope) [class$="_panel"]` 重置）—— 因为设置菜单不做透明

### 3.3 动态壁纸（MP4）

- 媒体入库：`video/mp4` 文件（≤300MB）以 Blob 存 IndexedDB，
  库条目 `kind: "video"`，缩略图渲染 `<video preload="metadata">` 显示首帧
- 播放：插件注入 `<video id="dsh-bg-video">` 到当前模式对应表面，
  `z-index:-1`、`object-fit:cover` 铺满、`muted+loop+autoplay+playsInline`
- 模糊/透明度直接作用于 video 元素本身；压暗遮罩与文字颜色仍来自样式表
- 布局渲染晚于插件激活：表面未出现时 500ms 重试，上限 20 次（10s）
- 切换/删除视频时 revoke 旧 object URL，删除时同步删除 IndexedDB blob

### 3.4 设置入口（BackgroundRow）

- 槽位：`ctx.slots.inject("settings.general.item", ...)`，`order: 11`
  —— 直接位于「通用 → 外观」行下方
- 预览：迷你三栏 mock（sidebar 1.4 : center 3 : details 1.8），
  按当前模式在对应段绘制背景，实时镜像页面效果
- 交互：启用开关、移除背景、三模式分段按钮、图片库缩略图（点击选中/×删除）、
  ＋上传（多选）、**粘贴剪贴板图片**、三个滑杆、文字颜色子区
- 保存失败（配额超限）显示错误提示

### 3.5 HMR 兼容

- 样式元素带 `data-plugin="dsh-bg"`，HMR 重载时旧 `<style>` 被移除、
  新 bundle 重新注入，无残留
- 修改 `lib/client.js` 后 client-hmr（500ms 轮询）自动热更新，无需重启服务

## 4. 安装

```bash
# 从项目目录安装到 web profile（自动加入 dsh.profile.bundles 层）
dsh plugin --profile web add file:./dsh-bg   # 在仓库父目录执行，或填本机实际路径
```

然后**重启 dsh web 服务**（关闭 start-harness 窗口重新运行），刷新浏览器。
重启后修改 `lib/client.js` 通过 client-hmr 自动热更新。

## 6. 项目结构

```
dsh-bg/
├── package.json        dsh.client（platform web，注入 slots）+ dsh.bundle.patch
├── cordis.patch.yml    插入 dsh-bg 插件行
├── README.md           使用说明
├── test-smoke.cjs      模块级冒烟测试
├── verify-cdp.mjs      CDP 真实浏览器验证脚本
└── lib/
    ├── index.js        host 侧占位（无行为）
    └── client.js       browser 侧：背景引擎 + 设置行 UI（~1000 行）
```

## 7. 已知限制与后续方向

- 图片单张 ≤ ~3.4MB（data URL 形式存 localStorage）、库上限 8 项、
  视频 ≤ 300MB（IndexedDB）
- 类名匹配依赖 DSH UI 布局的语义后缀，若上游重构去掉 `_sidebarCol` 等
  后缀需适配
- 后续可做：文字颜色**自动判定**（分析背景亮度自动选黑/白）、背景随机切换、
  上传图片压缩、多图轮播
